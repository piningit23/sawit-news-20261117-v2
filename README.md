A newspaper-broadsheet image summing up Tuesday 17 November 2026's world news — 42 verified stories from six continents on one front page, with a world map plotting every story (dots 1–42), a Kerch Bridge lead illustration, and market closes — drawn entirely in code.

v2 replaces v1 ("The World Today: 17 November 2026", 8 stories, no map): 5x more stories, a real map with country borders, six-column layout.

## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
Rebuild the image from scratch (deterministic, Pillow only):
```sh
python3 draw.py
```
